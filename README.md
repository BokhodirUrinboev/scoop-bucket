# Scoop bucket for Desk Arcade

[Desk Arcade](https://github.com/BokhodirUrinboev/DeskArcade) puts mini-games on top of your desktop in a
transparent overlay: hoops, archery, mini golf, air hockey, chess, durak, a desktop pet and more.

```powershell
scoop bucket add deskarcade https://github.com/BokhodirUrinboev/scoop-bucket
scoop install deskarcade/deskarcade
```

Upgrade with `scoop update deskarcade`, remove with `scoop uninstall deskarcade`. x64 and ARM64 are
supported, with the .NET runtime bundled.

The manifest is stamped from
[`packaging/scoop/deskarcade.json`](https://github.com/BokhodirUrinboev/DeskArcade/blob/main/packaging/scoop/deskarcade.json)
for each release.
